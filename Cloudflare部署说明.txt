图片相似度搜索工具 - Cloudflare 域名访问部署说明

重要说明
1. 这个工具不能完全放到 Cloudflare 上独立运行。
2. 原因：Cloudflare 服务器无法直接读取公司内网共享盘：
   \\Oygx2026\欧野图库区域
3. 正确方案是：
   公司内网电脑或服务器运行 Python 后台；
   Cloudflare Tunnel 提供外网/域名访问入口；
   业务员只打开 Cloudflare 域名使用。

推荐部署结构
1. 后台电脑：
   放在公司内网，必须能打开：
   \\Oygx2026\欧野图库区域
   \\Oygx2026\业务-运营共享文件\image_matcher_cloud_index

2. Cloudflare：
   绑定一个域名，例如：
   image-search.your-domain.com

3. 业务员：
   只需要打开上面的域名，不需要运行脚本。


第一次部署步骤

一、准备后台电脑
1. 选一台长期在线的公司电脑或服务器。
2. 把整个工具文件夹放到这台电脑。
3. 确认这台电脑能打开：
   \\Oygx2026\欧野图库区域
   \\Oygx2026\业务-运营共享文件\image_matcher_cloud_index
4. 双击 open_panel.vbs 测试本地能不能打开。
5. 如果本地可以打开，再继续配置 Cloudflare。


二、在 Cloudflare 创建 Tunnel
1. 打开 Cloudflare 后台：
   https://one.dash.cloudflare.com/

2. 进入：
   Networks
   -> Tunnels
   -> Create a tunnel

3. 选择：
   Cloudflared

4. 给 Tunnel 起名，例如：
   image-matcher

5. Cloudflare 会生成一段 token。
   保存这段 token，后面要用。


三、配置访问域名
在 Cloudflare Tunnel 的 Public Hostname 里新增：

Subdomain:
image-search

Domain:
选择你的公司域名

Service Type:
HTTP

URL:
127.0.0.1:5000

保存。


四、在后台电脑安装 cloudflared
下载地址：
https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/

选择 Windows 版本。

推荐做法：
把 cloudflared.exe 放到工具文件夹里，或者安装到系统 PATH。


五、设置 Tunnel Token
在后台电脑打开命令提示符，执行：

setx CLOUDFLARE_TUNNEL_TOKEN "这里粘贴 Cloudflare 给你的 token"

设置完成后，关闭命令提示符窗口。


六、启动 Cloudflare 版本
双击：
start_cloudflare_tunnel.bat

保持这个窗口运行。
业务员就可以打开你设置好的 Cloudflare 域名访问工具。


日常使用
1. 后台电脑不要关机。
2. start_cloudflare_tunnel.bat 要保持运行。
3. 业务员只打开 Cloudflare 域名。
4. 平时不要勾选“补建缺失指纹”，这样速度最快。
5. 需要补建新图片缓存时，建议下班后由一台后台电脑勾选运行。


如果打不开
1. 先在后台电脑打开：
   http://127.0.0.1:5000/

2. 如果本地打不开：
   说明 Python 后台没启动。
   重新双击 start_cloudflare_tunnel.bat。

3. 如果本地能打开，但 Cloudflare 域名打不开：
   检查 start_cloudflare_tunnel.bat 窗口有没有报错。
   检查 Cloudflare Tunnel 是否显示 Healthy。

4. 如果能打开页面，但搜不到图片：
   检查后台电脑是否能访问：
   \\Oygx2026\欧野图库区域


安全建议
Cloudflare 域名建议开启访问限制。
可以在 Cloudflare Zero Trust 里限制只有公司邮箱账号可以访问。
