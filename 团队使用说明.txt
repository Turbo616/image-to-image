云端案例图搜索工具 - 团队使用说明

一、打开方式

1. 先把压缩包完整解压到电脑文件夹里。
2. 双击 open_panel.vbs。
3. 程序会自动检查电脑上有没有 Python。
4. 如果没有 Python，会尝试自动安装。
5. 如果自动安装不了，会打开 Python 下载页面。安装时一定要勾选 Add python.exe to PATH。
6. Python 准备好后，程序会自动安装需要的依赖。
7. 工具会优先使用 vendor\wheels 里的离线依赖包，不需要每台电脑都能访问 Python 包下载网站。
8. 浏览器会自动打开 http://127.0.0.1:5000/

二、搜索范围

默认搜索范围是：
/team-folders/业务部区域/设计订单3D图资料/设计订单3D图资料/

这个适合日常搜索“设计订单 3D 图资料”，速度更可控。

如果要扩大到上一级整个业务部区域，在面板里点击：
扩大范围：整个业务部区域

点击后搜索目录会自动变成：
/team-folders/业务部区域

注意：第一次搜索整个业务部区域时，范围更大，建立指纹库会更久。后续会复用共享指纹库，速度会变快。

三、共享指纹库

工具默认使用共享指纹库：
\\Ouyeegx002\业务-运营共享文件夹\image_matcher_cloud_index

新版不会再把几十万张图片长期保存到共享盘里，只会保存很小的图片指纹数据库。
搜索结果里需要预览的图片，会保存到本次结果文件夹，不会塞进共享缓存目录。

四、使用时不要关闭什么

使用面板期间，请不要关闭最小化的 Image Matcher Server 窗口。
如果关闭了，网页会断开。重新双击 open_panel.vbs 即可恢复。

五、如果打不开

把这个日志文件发给管理员：
work\install_packages.log

如果提示依赖安装失败，请确认压缩包里有这个文件夹：
vendor\wheels

如果页面打开后中断，把这个日志发给管理员：
work\panel_server.log
